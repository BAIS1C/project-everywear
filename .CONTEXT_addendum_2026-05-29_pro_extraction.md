### Architectural decision locked

Gener8 4ever (free, $20 one-time) and Gener8 Pro ($13.37/mo) are now a hard product boundary with a single Gener8 shell and a code-level capability module boundary. No fork, no drift.

- **Gener8 4ever:** Song generation only. text2music payload. Song DiT model (xl-turbo). No Reference / Cover state in the React tree, no Pro UI mounted.
- **Gener8 Pro:** Reference + Cover capability module mounted into the Gener8 shell on a resolved entitlement gate. Capability model (xl-base or sftturbo50). Audio-slot payload.

The pill-bounce bug is eliminated as a side effect of this extraction: Pro state cannot exist in a 4ever user's tree, and the Pro module mount in Pro users' trees is gated on `entitlementResolved && canUseGener8Pro` rather than truthiness-checking a value that races auth hydration.

### Capability module pattern (reusable)

The applets/gener8/web/src/pro/ shape is the canonical reference for any future tier-gated capability module:

1. New directory at the applet level, named for the tier or capability.
2. Discriminated payload union exported from a builder file. Free-tier payload type cannot carry Pro fields.
3. Capability-only model resolver. Never returns a free-tier model for a Pro path.
4. Encapsulated state hook for any mode/state that should not leak into the free-tier component tree.
5. Vault picker (or analogous data picker) filtered by the tier's expected asset kinds.
6. `entitlementResolved && canUseFeature` gate, never truthiness-only.
7. Type-test coverage for the discriminated union mutual exclusion + runtime tests for mode-switch state cleanup and picker filter behaviour.

Apply to Vid Pro and AI Director planner once the shell AuthContext gets its own `entitlementResolved` flag.
