# ace-server

ACE-Step music generation inference server.

Consumed by: S3 Studio (Gener8 engine)

Serves the ACE-Step 1.5 model for music generation. The platform shell
manages lifecycle. S3 Studio's gener8 engine sends generation requests
via HTTP to the running ace-server instance.

## Source

Forked from ace-step-ui into "BASIC STEP STUDIO" for local hosting.
See Project Ace for the fork.
